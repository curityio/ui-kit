# Install and Usage

## Use in the Curity UI Kit monorepo

```js
import "@curity/ui-kit-css";
```

## Use in an external website or app

The UI Kit is not published to npm, so install it straight from GitHub.
```bash
npm i github:curityio/ui-kit#dev
```

Then import the stylesheet in your app's entry point:

```js
import "curity-ui-kit/src/common/css/lib/src/main.css";
```


## Without a module bundler

Projects that link stylesheets directly (plain HTML pages, server-rendered templates) need a single flat CSS file. Build it from the repository root:



```shell
git clone https://github.com/curityio/ui-kit.git
cd ui-kit
git checkout dev
npm run -w src/common/css/lib build
```

Then copy `src/common/css/lib/dist/index.css` into your project and link it:

```html
<link rel="stylesheet" href="index.css" />
```
