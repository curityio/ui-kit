# Base

## Common form elements

### Text input

<div className="form-field mw-40 mt2 mb4">
  <label className="block" for="text-example">Label</label>
  <input className="field w100" type="text" name="text-example" placeholder="Enter text" />
</div>

```html
<div className="form-field">
  <label className="block" for="text-example">Label</label>
  <input className="field w100" type="text" name="text-example" placeholder="Enter text" />
</div>
```

> Note: the `w100` class is used to make the input element take up the full width of its parent container.

## Form example

The `.form-field` class wraps a label and its control to give them consistent spacing. The
`.field` class styles the input, and `.w100` makes it fill the width of its parent. Labels
need no class — the `label` element is styled directly.

<form className="mx-auto mw-40 border-light p4 br-8 mt4 mb4">
  <h2>Sign In</h2>

<div className="form-field">
  <label for="username">Username</label>
  <input className="field w100" type="text" name="username" required autoFocus />
</div>
<div className="form-field">
  <label for="password">Password </label>
  <input className="field w100" type="password" name="password" required />
</div>

  <div className="form-field py2">
  <label for="department-select">Choose a department:</label>

    <select name="department" id="department-select">
    <option value="">Select department</option>
    <option value="engineering">Engineering</option>
    <option value="finance">Finance</option>
    <option value="human-resources">Human Resources</option>
    <option value="legal">Legal</option>
    <option value="sales">Sales</option>
    <option value="support">Support</option>
    </select>

    </div>

<div className="form-field py2">
  <input className="button button-primary button-medium w100" type="submit" value="Login" />
</div>
