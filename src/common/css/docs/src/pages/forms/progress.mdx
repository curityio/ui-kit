# Progress bar

A progress bar is two elements: an outer `.progress` track, and an inner `.progress` fill
whose `width` you set to the current percentage.

The fill takes a colour modifier — `.progress-success`, `.progress-info`,
`.progress-warning` or `.progress-danger`. Put the modifier on the fill, not the track.

Give the fill `role="progressbar"` with `aria-valuenow`, `aria-valuemin` and
`aria-valuemax` so the value is announced. `max` and `value` are attributes of the
`<progress>` element and do nothing on a `div`.

<div>
  <label for="upload-progress">File progress 70%</label>
  <div class="progress">
    <div
      role="progressbar"
      class="progress progress-success"
      id="upload-progress"
      aria-valuenow="70"
      aria-valuemin="0"
      aria-valuemax="100"
      style="width: 70%"
    ></div>
  </div>
</div>

## Colour variants

| Class | Use for |
| --- | --- |
| `.progress-success` | Completed or on-track work |
| `.progress-info` | Neutral progress, no judgement implied |
| `.progress-warning` | Approaching a limit, such as a quota |
| `.progress-danger` | Over a limit, or a failing operation |
