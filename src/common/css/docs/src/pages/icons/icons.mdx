# Curity UI Icons React

This is the **`@curity/ui-kit-icons`** workspace package, in
[`src/common/icons`](https://github.com/curityio/ui-kit/tree/dev/src/common/icons) of this
repository. The components are generated from the SVG sources there, so a new icon is added
by adding it to that package and rebuilding, not by editing this page.

Library to use selected Curity UI icons in public React based projects.

## Use icons

Import icons like this

```js
import { IconGeneralClose } from '@curity/ui-kit-icons';
```

Use an icon like this

```js
<IconGeneralClose />
```

<IconGeneralClose width="24" height="24" />

An icon has no intrinsic size: it fills its container unless you give it `width` and
`height`. It is drawn with `currentColor`, so it takes the text colour around it until
you pass `color`.

```js
<IconGeneralClose color="blue" width="48" height="48"/>
```

<IconGeneralClose color="blue" width="48" height="48"/>
