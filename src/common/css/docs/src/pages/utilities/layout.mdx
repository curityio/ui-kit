# Layout Utilities

Layout utilities provide classes for controlling common layout properties including display, position, overflow, and z-index.

## Display

Control the display property of elements.

- `.display-none` - `display: none`, removing the element from the layout
- `.block` - `display: block`
- `.inline` - `display: inline`
- `.inline-block` - `display: inline-block`
- `.flex` - `display: flex`
- `.inline-flex` - `display: inline-flex`
- `.table` / `.table-cell` - `display: table` / `table-cell`

## Position

Control the position property of elements. There is no class for `position: static` —
that is the browser default, so remove the positioning class instead.

- `.relative` - `position: relative`, and the containing block for absolute children
- `.absolute` - `position: absolute`
- `.fixed` - `position: fixed`, pinned to the viewport
- `.sticky` - `position: sticky`

## Overflow

Control how content overflow is handled. There is no class for `overflow: visible` —
that is the default.

- `.overflow-auto` - scrollbars only when the content needs them
- `.overflow-hidden` - clip the overflow, no scrolling
- `.overflow-scroll` - always show the scroll area
- `.overflow-x-hidden` / `.overflow-y-hidden` - clip one axis only

## Z-Index

Control the stacking order of positioned elements. `.z-1` through `.z-10` set
`z-index: 1` to `10`; they only take effect on a positioned element, so pair them with
`.relative`, `.absolute`, `.fixed` or `.sticky`. There is no `.z-0` — the default
`z-index: auto` is what an unstyled element already has.

## Visibility

Control element visibility. The three differ in what they do to layout and to screen readers:

- `.hidden` - `visibility: hidden`; invisible, still takes up its space, not read out
- `.hide` - `display: none`; removed from the layout and not read out
- `.visuallyhidden` - off-screen but still announced, for text that only screen readers need
